# GDD atualizado — Ecos do Cretáceo: Projeto Retorno

Arquivo principal: **GDD_Games_Atualizado.tex**.

Esta revisão mantém a campanha com cinco níveis e diferencia o Nível 1
implementado dos sistemas/níveis futuros. Preserva os dados da equipe
informados no texto enviado.

## Abrir no Overleaf

1. Escolha **New Project → Upload Project**.
2. Envie **GDD_Atualizado_Overleaf.zip**.
3. Se necessário, selecione **GDD_Games_Atualizado.tex** como Main document.
4. Use o compilador **pdfLaTeX** e recompile para atualizar o sumário.

O ZIP contém o documento completo, este arquivo e a pasta Figuras.
Não contém o projeto Unity nem pacotes de terceiros.

## Abrir no TeXstudio

Abra o .tex mantendo Figuras na mesma pasta. Compile duas vezes com
pdfLaTeX para atualizar sumário e referências. TeXstudio é o editor;
é necessário ter uma distribuição LaTeX instalada para compilar.

## Validação realizada

- Estrutura de ambientes e chaves verificada.
- Cinco níveis preservados, quatro identificados como planejamento.
- Controles e progressão conferidos com scripts e relatórios atuais.
- Três imagens reais do jogo incluídas.
- Requisitos confrontados com o PDF do professor, extraído localmente.

**O PDF não foi compilado neste ambiente**, pois não foi localizado
um compilador LaTeX. A verificação estrutural não garante paginação
ou ausência de avisos de layout; conferir o resultado após compilar.

O GDD PDF anterior e o enunciado permanecem em Docs/Referencias.
A fonte recebida foi preservada em Docs/Backups/GDD.
